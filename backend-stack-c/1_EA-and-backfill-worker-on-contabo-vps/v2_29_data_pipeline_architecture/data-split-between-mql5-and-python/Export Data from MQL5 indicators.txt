Export Data from MQL5 indicators — the COMPLETE export contract
==================================================================

Updated 2026-09-09. MQL5 is now the single source of every market_data value;
there is no Python calculation stack in the pipeline. This file therefore lists
EVERY column each indicator exports, not just the former "admin layer".
(The old companion file, "Python stacks calculation.txt", listed the values
Python used to recompute; it moved to
calculation-split-between-mt5-and-python-PENDING-PROJECT/ along with the code.)

These are the literal header strings the .mq5 files write. They are NOT uniform
(Title_Case line values vs lower_snake admin columns; the zigzag metrics carry
no source prefix at all) — the collector's SOURCES registry maps each to its
staging column. Do not "tidy" them to match each other; they must match what
MetaTrader actually writes.

The 4 leading keys (timestamp, symbol, timeframe, close) appear on every source
and are the cross-source validation contract.
