Engineering Blueprint

Data Ingestion & Serving Pipeline

โครงสร้างการทำงานตั้งแต่ Ingestion ต้นทางไปจนถึง Client Web/App ผ่าน Redis Microservices

1

Data Ingestion

• MT5 Broker: XAUUSD, EURUSD, GBPUSD, AUDUSD, USDCHF (Tick/Intraday)
• Yahoo Finance: USDTHB=X, USDAED=X, USDHKD=X, USDJPY=X, USDINR=X, USDTRY=X (Every 5-15 mins)

2

Normalization

• แปลง Spot เป็น USD/Gram Pure โดยหาร 31.1035
• บริหารทิศทาง FX: หารด้วย Base Quote (EUR, GBP, AUD) หรือคูณด้วย USD Pair (AED, HKD, THB, etc.)

3

Dynamic Tax & Units

• ดึงพารามิเตอร์ภาษี/พรีเมียมจาก Config DB (India Duty 6%, JCT 10%, Grand Bazaar 1.5%)
• คำนวณหน่วยเฉพาะ: บาททองคำ, Tola, Tael, Sovereign, Çeyrek

4

Cache & Delivery

• บันทึก JSON ลง Redis Cache (TTL: 60-300s)
• ส่งต่อผ่าน REST API & WebSocket ไปยัง Mobile App, Web Trading และ Dashboard
