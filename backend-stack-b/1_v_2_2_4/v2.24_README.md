# SimpleDataCollector v2.24 - Implementation Guide

## 🎯 Overview

Version 2.24 is a **production-ready multi-symbol data collector** with:

- ✅ Multi-symbol support (3-5 symbols per terminal)
- ✅ Redis primary path (fast queue publishing)
- ✅ SQLite fallback (safety net only when Redis fails)
- ✅ Eightcap broker symbol detection (.i suffix auto-detect)
- ✅ Single SQLite file per symbol
- ✅ Backfill queue tracking
- ✅ Real-time statistics monitoring

## 🏗️ Architecture

```
MT5 Terminal
     ↓
Collect Bar Data (57 columns)
     ↓
Try Redis Publish ────┐
     ↓                │
  Success?            │ Failed
     ✅               ❌
     │               │
     │               ↓
     │         Write SQLite Backup
     │         Mark for Backfill
     │               │
     └───────────────┘
           Done
```

**NOT parallel - Sequential logic!**

## 🐍 Python Backfill Script

Create `backfill_worker.py`:

```python
import sqlite3
import redis
import json
import time
from pathlib import Path

redis_client = redis.Redis(
    host='your-redis.upstash.io',
    port=6379,
    password='your-token',
    ssl=True
)

DATABASE_DIR = Path('C:/Scripts/database')
SYMBOLS = ['btcusd', 'ethusd', 'xauusd']  # Sanitized names

def backfill_from_sqlite():
    total = 0

    for symbol in SYMBOLS:
        db_path = DATABASE_DIR / f"{symbol}.db"
        if not db_path.exists():
            continue

        conn = sqlite3.connect(str(db_path))
        conn.row_factory = sqlite3.Row
        cursor = conn.cursor()

        # Get all bars (these are Redis failures)
        cursor.execute(f"SELECT * FROM {symbol}")
        rows = cursor.fetchall()

        for row in rows:
            # Convert to dict with all 57 columns
            payload = dict(row)

            # Push to Redis
            redis_client.lpush('market-data-sync', json.dumps(payload))

            # Delete from SQLite
            cursor.execute(
                f"DELETE FROM {symbol} WHERE timestamp=? AND timeframe=?",
                (row['timestamp'], row['timeframe'])
            )
            conn.commit()
            total += 1

        conn.close()

    return total

if __name__ == "__main__":
    while True:
        count = backfill_from_sqlite()
        if count > 0:
            print(f"✅ Backfilled {count} bars")
        time.sleep(300)  # 5 minutes
```
