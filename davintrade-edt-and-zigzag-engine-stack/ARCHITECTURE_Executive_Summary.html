1 · What we are building

Six MT5 indicators export market frames to tab-delimited text files every M15 bar. The backend parses them, runs four calculation stacks (each a one-to-one translation of an Excel sheet), and pushes a single JSON payload over WebSocket to the charting frontend. Each requirement maps one Excel sheet to one Python module:

Req 1

Validation

Cross-check that the 6 EDT model exports agree on shared market context. Emits one global all_validation gate.

Sheet G → calc/validation.py
Req 2

Combine After Validation

Gate-guarded coalesce of shared columns + per-model EDT geometry. The Top-Canvas dataset.

Sheet H → calc/combine.py
Req 3

Timestamp Adjustment

Snap ZigZag pivot timestamps onto the M15 / 5-min grid, with a forming-pivot guard.

Sheet J → calc/timestamp_adjust.py
Req 4

EQH / EQL Summary

Detect Equal Highs/Lows, average into S/R levels, emit the 6 most-recent horizontal lines.

Sheet K → calc/eqh_eql.py
Two independent pipelines, one frontend. The centroid workbook drives the Top Canvas (Req 1 → Req 2: EDT channels + SSA). The zigzag workbook drives the Bottom Canvas (Req 3 → Req 4: ZigZag vectors + EQH/EQL lines). They converge only at serialization.

Dependency tiers

  • Core calc (required): python>=3.11, pandas>=2.0, numpy>=1.24
  • I/O & validation: pandera>=0.18 (or pydantic>=2), watchdog
  • Transport (out of scope): fastapi, uvicorn[standard], websockets, orjson
  • Dev/test: pytest>=8, openpyxl>=3.1

Why pandas / NumPy

Each sheet is ≤3001 rows and every rule is column-wise — equality, coalesce, shift, masked classification, mean. Vectorized ops deliver exact Excel parity with less code and comfortably meet the per-tick recompute budget. The only sequential reads are the next-row guards (shift(-1)), themselves vectorized.

4 · Build order & definition of done

  • Build bottom-up: Stage 0 → 1 → 2/3 → 4 → 5 → 6, sharing calc/timegrid.py early.
  • The workbooks are the oracle. Implement the pytest parity harness first using openpyxl(data_only=True) to extract golden CSVs, then refactor freely.
  • Green parity = done. Reproduce the six EQH/EQL line values (4515.51, 4521.39, 4370.90, 4492.21, 4538.40, 4487.80), all_validation = True, and the verified timestamp pairs.
Non-negotiable semantics (full detail in §9 of the spec): Excel CEILING/INT/MROUND ≠ Python banker's rounding · 5-minute grid even on M15 · empty-vs-empty compares equal · all_validation is a single global gate · gate-false blanks all of Combine · EQ tolerance is ±0.25% · publish when Count≥3 OR any Important EQHL · never serialize "" (emit null) · all 6 EDT sources are row-aligned.
