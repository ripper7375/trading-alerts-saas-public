## 2. ReferenceError: clearImmediate is not defined

Certain tests (stack-c-forbidden.test.ts) crash with:

```
ReferenceError: clearImmediate is not defined
    at undici/lib/core/connect.js:211:9
```

This means your test environment (probably jsdom) does not provide `clearImmediate`. The undici library is designed for Node.js, which does provide this global, but jsdom simulates browsers and omits it.

**Solution:**

- Mock or polyfill `clearImmediate` when running tests in jsdom. Add this before your tests run (e.g., in your jest setup file):

```js
// jest.setup.js or equivalent
global.clearImmediate =
  global.clearImmediate ||
  function (id) {
    clearTimeout(id);
  };
global.setImmediate =
  global.setImmediate ||
  function (fn, ...args) {
    return setTimeout(fn, 0, ...args);
  };
```

- Reference: https://github.com/jsdom/jsdom/issues/3363
