The job is failing due to a **version mismatch** between your lockfile and package.json manifests for Prisma dependencies.

### Root Cause

Your root `package.json` specifies Prisma `^6.19.2`, but `frontend/package.json` still has the older `^5.22.0` version. The lockfile contains the older version, causing the mismatch error.

### Fix

Update `frontend/package.json` to match the Prisma versions in your root package.json:

```json
{
  "dependencies": {
    "@prisma/client": "^6.19.2"
    // ... other dependencies
  },
  "devDependencies": {
    "prisma": "^6.19.2"
    // ... other dev dependencies
  }
}
```

**Lines to change in `frontend/package.json`:**

- Line 29: Change `"@prisma/client": "^5.22.0"` to `"@prisma/client": "^6.19.2"`
- Line 90: Change `"prisma": "^5.22.0"` to `"prisma": "^6.19.2"`

After making this change, regenerate your lockfile:

```bash
pnpm install
```

This will resolve the dependency mismatch and allow the tests to run. The secondary codecov error will also be resolved once tests can execute successfully.
