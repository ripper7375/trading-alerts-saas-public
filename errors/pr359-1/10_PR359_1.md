The issue is clear: there's a **dependency version mismatch** between your `package.json` (manifest) and `package-lock.json` (lockfile).

## Problem

- `@prisma/client` and `prisma` are specified as `^6.19.2` in your `package.json`
- But your `package-lock.json` has them locked at `^5.22.0`

## Solution

Update your lockfile to match the manifest versions by running:

```bash
npm install @prisma/client@^6.19.2 prisma@^6.19.2
```

Or simply:

```bash
npm install
```

This will regenerate the `package-lock.json` with the correct versions that match your `package.json`.

After running this command locally, commit and push the updated `package-lock.json` to fix the CI failure.

**Note:** Make sure both `@prisma/client` and `prisma` are on the same version to avoid compatibility issues. After updating, you may also need to regenerate the Prisma client:

```bash
npx prisma generate
```
