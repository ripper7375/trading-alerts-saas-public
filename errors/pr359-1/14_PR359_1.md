The job is failing due to a Prisma version mismatch between your package.json files. The lockfile has `^5.22.0` while some manifests specify `^6.19.2`.

### Root Cause

Looking at your package files:

- **Root `package.json`**: Uses Prisma `^6.19.2` (lines 90, 162)
- **`frontend/package.json`**: Still uses Prisma `^5.22.0` (lines 29, 90)

### Fix

Update `frontend/package.json` to match the root package versions:

```json
{
  "dependencies": {
    "@prisma/client": "^6.19.2"
    // ... other dependencies
  },
  "devDependencies": {
    "prisma": "^6.19.2"
    // ... other devDependencies
  }
}
```

**Changes needed in [`frontend/package.json`](https://github.com/ripper7375/trading-alerts-saas-public/blob/e85ed41c8055f93e96bddf1e61c6109697777c77/frontend/package.json):**

- Line 29: Change `"@prisma/client": "^5.22.0"` → `"@prisma/client": "^6.19.2"`
- Line 90: Change `"prisma": "^5.22.0"` → `"prisma": "^6.19.2"`

After making these changes, regenerate your lockfile:

```bash
pnpm install
```

Then commit both the updated `frontend/package.json` and the regenerated lockfile.
