The job is failing due to **mismatched Prisma dependencies** between your lockfile and package.json. The lockfile has Prisma v5.22.0, but the manifest (package.json) specifies v6.19.2.

## Solution

You need to update your lockfile to match the package.json versions. Run the following command:

```bash
pnpm install
```

This will update your `pnpm-lock.yaml` to align with the Prisma versions specified in your `package.json`.

### If the issue persists:

If you want to ensure a clean state, you can:

```bash
# Remove the lockfile and node_modules
rm pnpm-lock.yaml
rm -rf node_modules

# Reinstall dependencies
pnpm install
```

Then commit the updated `pnpm-lock.yaml` file.

### Root Cause

The mismatch occurred because:

- Your `package.json` has `@prisma/client` and `prisma` at `^6.19.2`
- Your `pnpm-lock.yaml` still references `^5.22.0`

This typically happens when dependencies are updated in `package.json` but the lockfile wasn't regenerated or committed.

**Note:** The codecov error is a secondary failure that occurred because the tests didn't run successfully due to the dependency mismatch.
