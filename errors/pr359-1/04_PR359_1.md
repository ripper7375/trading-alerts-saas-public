- **@prisma/client**: lockfile has `^5.22.0`, manifest has `^6.19.2`
- **prisma**: lockfile has `^5.22.0`, manifest has `^6.19.2`

### Root Cause

Your root `package.json` was updated to Prisma 6.19.2, but:

1. The `package-lock.json` still references the old 5.22.0 versions
2. The `frontend/package.json` also still uses 5.22.0

### Fix

You need to synchronize the versions and regenerate the lockfile. Run these commands:

```bash
# Update frontend package.json to match root
cd frontend
npm install @prisma/client@^6.19.2 prisma@^6.19.2

# Return to root and regenerate the lockfile
cd ..
npm install

# Or if using pnpm (as suggested by your scripts)
pnpm install
```

Alternatively, if you want to keep Prisma 5.22.0 across the project, update the root `package.json` back to `^5.22.0`:

```json
{
  "dependencies": {
    "@prisma/client": "^5.22.0",
    ...
  },
  "devDependencies": {
    "prisma": "^5.22.0",
    ...
  }
}
```

Then run `npm install` or `pnpm install` to sync the lockfile.
