The job is failing due to a **version mismatch between your `package.json` and `package-lock.json`** for Prisma packages:

- **Lockfile:** `@prisma/client` and `prisma` are at `^5.22.0`
- **Manifest (package.json):** Both are at `^6.19.2`

### Root Cause

Your root `package.json` has been updated to Prisma v6.19.2, but the `package-lock.json` still references v5.22.0. This typically happens when `package.json` was manually edited without running `npm install` to update the lockfile.

### Fix

Run the following command to regenerate your lockfile:

```bash
npm install
```

This will update `package-lock.json` to match the versions in `package.json`. Then commit the updated lockfile:

```bash
git add package-lock.json
git commit -m "Update package-lock.json for Prisma 6.19.2"
git push
```
