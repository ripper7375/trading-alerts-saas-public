The tests are failing because the module `lib/api` doesn't exist. All three test files are trying to import from `@/lib/api`, which cannot be found.

### Root Cause

```
Cannot find module '../../lib/api' from '__tests__/lib/api/stack-a-client. test.ts'
```

The tests expect to import:

```typescript
const { api } = await import('@/lib/api');
```

But this module is missing from the codebase.

### Fix

const BASE_URL =
  typeof window !== 'undefined' ? '' : process.env.NEXT_PUBLIC_API_URL || '';

// Helper function for API calls
async function apiCall(endpoint: string, options: RequestInit = {}) {
  const response = await fetch(`${BASE_URL}${endpoint}`, {
    headers: {
      'Content-Type': 'application/json',
      ...options.headers,
    },
    ...options,
  });

  if (!response.ok) {
    const error = await response
      .json()
      .catch(() => ({ error: response.statusText }));
    throw new Error(error.error || `API Error: ${response.status}`);
  }

  return response.json();
}
