### 2. Undici/Jsdom/Node Compatibility Issues

Several tests failed with:

- `ReferenceError: clearImmediate is not defined`
- `TypeError: markResourceTiming is not a function`
  These came from undici (HTTP fetch lib) and jsdom (browser simulation).

**Solution:**  
This is a known problem when using undici with jsdom under Jest, as the Node test environment doesn't polyfill browser globals or timers like `clearImmediate`.  
You can fix this by requiring a polyfill for clearImmediate before your tests, or downgrading undici, or switching to node's native fetch as appropriate for your environment.

Add this to your Jest setup file (or top of the problematic test files):

```js
// jest.setup.js
global.clearImmediate =
  global.clearImmediate ||
  function (fn, ...args) {
    return setTimeout(fn, 0, ...args);
  };
```

Or, for TypeScript:

```ts
// jest.setup.ts
(global as any).clearImmediate =
  (global as any).clearImmediate ||
  function (fn: any, ...args: any[]) {
    return setTimeout(fn, 0, ...args);
  };
```

Also:

- If markResourceTiming is not needed for your use-case, you can mock it in setup as well:

```js
window.markResourceTiming = window.markResourceTiming || function () {};
```
