The failing job log indicates the root cause is a missing CRON_SECRET environment variable when calling POST /api/cron/process-pending-disbursements. In your code, route.ts checks for process.env['CRON_SECRET'] and will fail with "CRON_SECRET not configured" (500 error) if it's not set.

**Solution:**  
Ensure the CRON_SECRET environment variable is defined in your CI environment.

For example, in GitHub Actions, add this to your workflow yaml under env or as a secret:

```yaml
env:
  CRON_SECRET: your-secret-value
```

or

```yaml
- name: Set up env
  run: echo "CRON_SECRET=your-secret-value" >> $GITHUB_ENV
```

If you want the tests to pass locally or in CI, make sure CRON_SECRET is set wherever the test or server runs.

**Summary of Change:**  
Add CRON_SECRET to your environment. This will let the process-pending-disbursements job authenticate and resolve the test failures like:

