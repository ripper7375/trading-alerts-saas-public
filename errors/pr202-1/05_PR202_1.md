I'll analyze the failing job to find a solution for you. ## Solution

The build is failing because TypeScript cannot find type definitions for the `pg` module. The error occurs at line 10 in `lib/db/postgresql.ts` where you're importing from `pg`.

### Fix

Install the `@types/pg` package as a dev dependency:

```bash
pnpm add -D @types/pg
```

Or if using npm:

```bash
npm install --save-dev @types/pg
```

### Why This Happens

The `pg` package is written in JavaScript and doesn't include TypeScript type definitions. The separate `@types/pg` package provides the type declarations needed for TypeScript compilation.

### Code Reference

The failing import is at [line 10 of lib/db/postgresql.ts](https://github.com/ripper7375/trading-alerts-saas-public/blob/dd4f8261991b268afb77c9ed98d1d478107a1324/lib/db/postgresql.ts#L10):

```typescript
import { Pool, PoolConfig } from 'pg';
```

Once you add `@types/pg` to your dev dependencies and commit the updated `package.json`, the CI build should pass.
