**2. Update line 23 to use bracket notation for `process.env`:**

```typescript
    process.env['POSTGRESQL_URI'] || process.env['DATABASE_URL'],
  max: 20,
  idleTimeoutMillis: 30000,
  connectionTimeoutMillis: 2000,

```

### Explanation:

TypeScript's strict mode (with `noUncheckedIndexedAccess` or similar) requires bracket notation when accessing properties that come from index signatures. The `process.env` object uses an index signature, so `process.env. POSTGRESQL_URI` should be `process.env['POSTGRESQL_URI']`.

Additionally, the `@types/pg` package provides TypeScript type definitions for the `pg` module, which resolves the implicit 'any' type error.
