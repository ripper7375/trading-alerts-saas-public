The build is failing because TypeScript cannot find type declarations for the `pg` module. The error occurs at line 10 in `lib/db/postgresql.ts` where you're importing from `pg`.

**Fix:** Install the `@types/pg` package as a dev dependency.

Run this command:

```bash
pnpm add -D @types/pg
```

Or if using npm:

```bash
npm install --save-dev @types/pg
```

This will provide TypeScript with the necessary type definitions for the PostgreSQL `pg` package, allowing the build to complete successfully. The `@types/pg` package contains TypeScript declaration files that tell the compiler what types are available in the `pg` module.
