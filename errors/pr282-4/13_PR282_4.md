The TypeScript error is occurring because `process.env.NEXT_PUBLIC_API_URL` is being accessed with dot notation instead of bracket notation. TypeScript's strict mode requires bracket notation for index signature properties.

**File:** `lib/api/index.ts` (line 9)

**Change this:**

```typescript
const BASE_URL =
  typeof window !== 'undefined' ? '' : process.env.NEXT_PUBLIC_API_URL || '';
```

**To this:**

```typescript
const BASE_URL =
  typeof window !== 'undefined' ? '' : process.env['NEXT_PUBLIC_API_URL'] || '';
```

This change uses bracket notation `['NEXT_PUBLIC_API_URL']` instead of dot notation `.NEXT_PUBLIC_API_URL`, which aligns with how environment variables are accessed elsewhere in your codebase (e.g., in `frontend/lib/api/index.ts` line 51).
