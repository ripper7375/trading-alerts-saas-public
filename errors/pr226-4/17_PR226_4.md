The failure is due to using arguments of type string for symbol and timeframe in functions like getIndicatorDataFromDb and getDataFreshness in lib/db/queries.ts. TypeScript is expecting these to be specific union types (e.g., "BTCUSD" | "EURUSD" | ... for symbol and "H1" | "H4" | ... for timeframe) but receives plain string, causing errors like:

- lib/db/queries.ts(24,48): error TS2345: Argument of type 'string' is not assignable to parameter of type '..."BTCUSD" | ...'.
- lib/db/queries.ts(25,54): error TS2345: Argument of type 'string' is not assignable to parameter of type '..."H1" | ...'.

Solution:

Update the function signatures to accept only the specific union types defined for symbol and timeframe. These are likely exported from @/lib/constants/business-rules.

For example, if VALID_SYMBOLS and VALID_TIMEFRAMES are typed as:

- type Symbol = "BTCUSD" | "EURUSD" | ...;
- type Timeframe = "H1" | "H4" | ...;

Update all relevant function signatures. For example:

```typescript
import type { Symbol, Timeframe } from '@/lib/constants/business-rules';

export async function getIndicatorDataFromDb(
  symbol: Symbol,
  timeframe: Timeframe,
  limit: number = 1000
): Promise<IndicatorData> { ... }

export async function getDataFreshness(
  symbol: Symbol,
  timeframe: Timeframe
): Promise<Date | null> { ... }
```

Then, ensure that callers pass valid Symbol and Timeframe values.

Alternatively, if accepting strings from user input, cast or validate them before passing to these functions.
