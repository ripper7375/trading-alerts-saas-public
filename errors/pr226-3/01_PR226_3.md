### 3. **Jest: Unexpected Token – Parsing Errors**

**Error:**  
`Jest encountered an unexpected token... Jest failed to parse a file. This happens ... when your code or its dependencies use non-standard JavaScript syntax`

**Solution:**  
Jest needs to transform code with Babel.

- Ensure your `jest.config.js` has proper `transform` settings for `.ts` and `.js` files.
- Make sure you have a Babel config for Jest.

**Code suggestion (`jest.config.js`):**

```js
module.exports = {
  transform: {
    '^.+\\.tsx?$': 'babel-jest',
    '^.+\\.jsx?$': 'babel-jest',
  },
  testEnvironment: 'jsdom', // or 'node' for non-browser code
};
```

And a sample Babel config (`babel.config.js`):

```js
module.exports = {
  presets: [
    '@babel/preset-env',
    '@babel/preset-typescript',
    '@babel/preset-react',
  ],
};
```
