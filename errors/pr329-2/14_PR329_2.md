The job is failing at the **Run ESLint** step. The error indicates that Next.js is incorrectly interpreting "lint" as a directory path:

```
Invalid project directory provided, no such directory: /home/runner/work/trading-alerts-saas-public/trading-alerts-saas-public/lint
```

### Root Cause

The `pnpm run lint` command is executing `next lint` with incorrect arguments, causing Next.js to look for a directory named "lint" instead of running the linter on the project.

### Fix

Check your `package.json` file and ensure the `lint` script is correctly defined. It should look like:

```json
{
  "scripts": {
    "lint": "next lint"
  }
}
```

**Common issues to avoid:**

- Don't have `"lint": "next lint lint"` (duplicate "lint")
- Don't have extra directory arguments unless intentional
- Ensure there's no typo in the script definition

### Alternative Fix

If you want to specify the directory explicitly, use:

```json
{
  "scripts": {
    "lint": "next lint ."
  }
}
```

This tells Next.js to lint the current directory (`.`) instead of looking for a directory called "lint".

After fixing the package.json, commit and push the changes to re-run the workflow.
