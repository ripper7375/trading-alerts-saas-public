The job failed because the build is using Turbopack with a webpack config, but there’s no Turbopack config present. Next.js recommends adding a turbopack config or explicitly specifying which bundler to use. To solve this, update your next.config.js by adding an empty Turbopack configuration under the experimental property:

```js
experimental: {
  serverActions: {
    bodySizeLimit: '2mb',
  },
  turbopack: {}, // <-- Add this line
},
```

Apply this to both next.config.js files in your project (such as at the root and under frontend/). This silences the error and ensures correct Next.js bundler behavior.

Reference: See https://nextjs.org/docs/app/api-reference/next-config-js/turbopack for more info.
