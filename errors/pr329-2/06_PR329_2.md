The tests are failing because of an issue with the `undici` module import in `jest.setup.js` at line 28. The `require('undici')` call is causing all test suites to fail before they can even run.

### Root Cause

The error occurs in the Web API polyfill section of your Jest setup file. The `undici` package is likely having ESM/CommonJS compatibility issues with Jest.

### Recommended Fix

Replace the `undici` import with a more Jest-friendly approach. Update **jest.setup.js** lines 24-33:

```javascript
// Polyfill Web API globals (Request, Response, Headers, etc.) for jsdom environment
// Required by next/server and other packages that use Web APIs
if (typeof global.Request === 'undefined') {
  // Option 1: Use native Node.js fetch (Node 18+)
  const {
    fetch,
    Request,
    Response,
    Headers,
    FormData,
  } = require('node:undici');
  global.fetch = fetch;
  global.Request = Request;
  global.Response = Response;
  global.Headers = Headers;
  global.FormData = FormData;
}
```

### Alternative Solution

If the above doesn't work, use `whatwg-fetch` instead, which is more stable in Jest environments:

1. Install the package:

```bash
pnpm add -D whatwg-fetch
```

2. Update jest.setup.js:

```javascript
// Polyfill Web API globals for jsdom environment
if (typeof global.fetch === 'undefined') {
  require('whatwg-fetch');
}
```
