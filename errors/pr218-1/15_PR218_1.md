```typescript
connectionString: process.env.POSTGRESQL_URI,
```

```typescript

```

### Complete corrected section (lines 13-23):

```typescript
function getPool(): Pool {
  if (!pool) {
    pool = new Pool({
      connectionString: process.env['POSTGRESQL_URI'],
      max: 20,
      idleTimeoutMillis: 30000,
      connectionTimeoutMillis: 2000,
    });
  }
  return pool;
}
```
