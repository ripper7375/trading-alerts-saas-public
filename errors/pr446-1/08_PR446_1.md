The job is failing at TypeScript compile time due to this error:

- `hooks/use-ohlcv-socket.ts(76,19): error TS4111: Property 'NEXT_PUBLIC_MT5_WS_URL' comes from an index signature, so it must be accessed with ['NEXT_PUBLIC_MT5_WS_URL'].`

### Fix

Update the environment variable access to use bracket notation (required when `process.env` is typed with an index signature under your TS settings).

**Change in** `hooks/use-ohlcv-socket.ts` (around line 76, ref `d09f59ad41f5d801c5e38f4900dee0d4d2513c78`):

```ts
const wsUrl = process.env['NEXT_PUBLIC_MT5_WS_URL'] ?? 'http://localhost:5001';
```

That’s all that’s needed to resolve TS4111 and unblock the build.
