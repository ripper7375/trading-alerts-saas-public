The TypeScript error occurs at **line 82** because `KeltnerChannelData` has properties (like `ultraExtremeUpper`) that don't exist in the `KELTNER_COLORS` constant object. When iterating over all keys of `KeltnerChannelData` and trying to use them to index `KELTNER_COLORS`, TypeScript correctly identifies this mismatch.

### Fix

Add a type guard to check if the band exists in `KELTNER_COLORS` before accessing it:

```tsx
(Object.keys(kc) as (keyof KeltnerChannelData)[]).forEach((band) => {
  const values = kc[band];
  if (!values || values.length === 0) return;

  // Add type guard to check if color exists
  if (!(band in KELTNER_COLORS)) {
    console.warn(`No color defined for Keltner band: ${band}`);
    return;
  }

  try {
    const series = chart.addLineSeries({
      color: KELTNER_COLORS[band as keyof typeof KELTNER_COLORS],
      lineWidth: band.includes('Middle') ? 3 : 2,
      priceLineVisible: false,
      lastValueVisible: false,
      crosshairMarkerVisible: false,
    });
```

Alternatively, you can define a fallback color:

```tsx
const color =
  band in KELTNER_COLORS
    ? KELTNER_COLORS[band as keyof typeof KELTNER_COLORS]
    : '#808080'; // fallback color

const series = chart.addLineSeries({
  color,
  lineWidth: band.includes('Middle') ? 3 : 2,
  priceLineVisible: false,
  lastValueVisible: false,
  crosshairMarkerVisible: false,
});
```

**Root cause**: The `KeltnerChannelData` type includes more properties than what's defined in `KELTNER_COLORS`. You should either add the missing color definitions to `KELTNER_COLORS` in `@/lib/tier/constants`, or use the type guard approach shown above to skip bands without defined colors.
