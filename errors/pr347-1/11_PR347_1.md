The TypeScript error occurs on **line 82** where `KELTNER_COLORS[band]` is accessed. The issue is that `KeltnerChannelData` has more properties (like `ultraExtremeUpper`) than are defined in the `KELTNER_COLORS` constant object, causing a type mismatch.

### Fix

Update the Keltner Channels rendering section to only iterate over bands that have color definitions:

**In `components/charts/pro-indicator-overlay.tsx`**, replace lines 76-109 with:

```tsx
(Object.keys(kc) as (keyof KeltnerChannelData)[]).forEach((band) => {
  const values = kc[band];
  if (!values || values.length === 0) return;

  // Only render bands that have a defined color
  if (!(band in KELTNER_COLORS)) return;

  try {
    const series = chart.addLineSeries({
      color: KELTNER_COLORS[band as keyof typeof KELTNER_COLORS],
      lineWidth: band.includes('Middle') ? 3 : 2,
      priceLineVisible: false,
      lastValueVisible: false,
      crosshairMarkerVisible: false,
    });

    // CRITICAL: Filter out undefined values AND ensure time exists
    const lineData: LineData<Time>[] = values
      .map((value, i) => ({
        time: timeData[i],
        value: value,
      }))
      .filter(
        (d): d is LineData<Time> =>
          d.time !== undefined && d.value !== undefined && !isNaN(d.value)
      );

    if (lineData.length > 0) {
      series.setData(lineData);
      currentSeriesRefs.set(`keltner_${band}`, series);
    } else {
      chart.removeSeries(series);
    }
  } catch (err) {
    console.error(`Failed to render Keltner band ${band}:`, err);
  }
});
```

**Key changes:**

- Added `if (!(band in KELTNER_COLORS)) return;` check on line 78 to skip bands without color definitions
- Cast `band` to `keyof typeof KELTNER_COLORS` on line 82 to satisfy TypeScript's type checker

This ensures only bands with defined colors are rendered, preventing the type error while maintaining functionality.
