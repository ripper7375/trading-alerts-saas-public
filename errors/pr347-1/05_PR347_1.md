The build is failing due to a **TypeScript type error on line 82** of `pro-indicator-overlay.tsx`. The issue is that `KELTNER_COLORS[band]` is trying to index the colors object with keys from `KeltnerChannelData`, but not all properties in `KeltnerChannelData` exist in `KELTNER_COLORS` (specifically `ultraExtremeUpper` is mentioned in the error).

### Fix

Update line 82 to safely handle missing color definitions:

```typescript
const series = chart.addLineSeries({
  color: KELTNER_COLORS[band as keyof typeof KELTNER_COLORS] ?? '#808080',
  lineWidth: band.includes('Middle') ? 3 : 2,
  priceLineVisible: false,
  lastValueVisible: false,
  crosshairMarkerVisible: false,
});
```

**OR** for a safer approach, add a check before the try block:

```typescript
(Object.keys(kc) as (keyof KeltnerChannelData)[]).forEach((band) => {
  const values = kc[band];
  if (!values || values.length === 0) return;

  // Skip if no color defined for this band
  if (!(band in KELTNER_COLORS)) return;

  try {
    const series = chart.addLineSeries({
      color: KELTNER_COLORS[band as keyof typeof KELTNER_COLORS],
      lineWidth: band.includes('Middle') ? 3 : 2,
      priceLineVisible: false,
      lastValueVisible: false,
      crosshairMarkerVisible: false,
    });
```

### Root Cause

The `KeltnerChannelData` type defines more band properties than what's available in `KELTNER_COLORS`. You'll also need to add the missing color definitions to your `KELTNER_COLORS` constant in `@/lib/tier/constants` to include `ultraExtremeUpper` and any other missing bands.
