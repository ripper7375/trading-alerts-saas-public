The failing job is caused by a lockfile mismatch: the logs state, “specifiers in the lockfile don't match specifiers in package.json: 1 dependencies were added: redis@^4.7.0”. This means the dependency redis@^4.7.0 is listed in your package.json but missing from package-lock.json.

Solution:

Run the following commands locally in the project root to synchronize your lockfile:
sh
pnpm install
git add package-lock.json pnpm-lock.yaml
git commit -m "Fix: update lockfile for redis@^4.7.0"
Push the updated lockfile to your branch. This will resolve the workflow error since both package.json and your lockfile will include redis@^4.7.0.
Why this works:
pnpm install regenerates the lockfile to match your declared dependencies, satisfying --frozen-lockfile checks in the workflow.

Refer to the workflow job definition here: .github/workflows/tests.yml)
