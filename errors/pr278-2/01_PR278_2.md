The failing job is due to the CRON_SECRET environment variable not being configured. The logs show:

- app/api/cron/process-pending-disbursements/route.ts checks for process.env['CRON_SECRET'].
- If it's missing, the error "CRON_SECRET not configured" is logged, and a 500 is returned.
- The check is here:
  ```typescript
  if (!cronSecret) {
    console.error('CRON_SECRET not configured');
    return NextResponse.json(
      { error: 'Cron job not configured' },
      { status: 500 }
    );
  }
  ```

Solution:

1. In your CI environment (GitHub Actions), add CRON_SECRET to the job or repository secrets.
2. In the workflow file (.github/workflows/ci-nextjs-progressive.yml), update the test job to inject the secret:

   ```yaml
   jobs:
     test:
       ...
       steps:
         ...
         - name: Run tests
           run: |
             echo "🧪 Running tests..."
             pnpm test
             echo "✅ Tests passed"
           env:
             CI: true
             CRON_SECRET: ${{ secrets.CRON_SECRET }}
   ```

3. Make sure the secret is set in your GitHub repository: Settings → Secrets → Actions → New repository secret.

Summary: Add the CRON_SECRET as a GitHub Actions secret and inject it into the environment for test and API jobs. This will resolve the "CRON_SECRET not configured" failure.
