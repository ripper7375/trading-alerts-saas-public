#### Immediate Fix

1. **Run Local Type Check:**
   In your project root, run:

   ```bash
   npm run validate:types
   # OR (frontend directory, if modular)
   pnpm run type-check
   ```

2. **Review TypeScript Errors:**
   This will show the cause—missing types, incorrect imports, or typing errors.

3. **Resolve the Errors:**
   Common quick fixes:
   - If you see "`cannot find module`": Ensure imports are correct and the file exists.
   - If you see "`property does not exist`" or "`type mismatch`": Adjust your type definitions or interfaces.
   - For Prisma, as you use manual stubs (`types/prisma-stubs.d.ts`), ensure these are up-to-date. Regenerate with:
     ```bash
     pnpm run db:generate
     ```

#### Example: How to Repair a Type Error

Suppose the failure is:

```
error TS2339: Property 'price' does not exist on type 'Alert'.
```

Fix this in your relevant TypeScript file:

```ts
interface Alert {
  price: number; // Ensure this matches schema
  // ...other fields
}
```

Or, correct the usage if the field name changed.
