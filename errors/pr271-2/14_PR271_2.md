### 2. TypeScript: "error is of type 'unknown'"

Example lines:

- (91, 15), (97, 37), and (97, 63) in frontend/app/api-test/page.tsx

Solution: Narrow the error to `ApiError` or `Error` before accessing its properties. For example:

Current code:

```tsx
catch (error) {
  if (error instanceof ApiError) {
    if (error.status === 404) {
      addResult( ... );
    } else {
      addResult(`API Error: ${error.message} (Status: ${error.status})`, 'error');
    }
  }
}
```

If you access `error.message` or `error.status` outside of a type guard, TypeScript will warn.

**Fix:**
Add an else block or log a generic message:

```tsx
catch (error) {
  if (error instanceof ApiError) {
    // handle
  } else if (error instanceof Error) {
    addResult(`Error: ${error.message}`, 'error');
  } else {
    addResult('Unknown error occurred', 'error');
  }
}
```
