1. The polyfill for clearImmediate is assigning a function with parameter (id: Timeout), but clearImmediate expects (immediate: Immediate | undefined). Change:

```typescript
global.clearImmediate = function (id: NodeJS.Timeout) {
  return clearTimeout(id);
};
```

to:

```typescript
global.clearImmediate = function (immediate?: NodeJS.Immediate) {
  return clearTimeout(immediate as any);
};
```

2. The polyfill for setImmediate is missing the required **promisify** property. Use the following:

```typescript
global.setImmediate = Object.assign(
  function (callback: (...args: any[]) => void, ...args: any[]) {
    return setTimeout(callback, 0, ...args);
  },
  { __promisify__: function () {} }
);
```

if (
