Stack A · Python
Timestamp Normalisation
stack_a/normalise.py
Step 1 — Unix → Excel serial: ts/86400+25569
Step 2 — Round 5-min slot: ceil(int(s×1440)/1440×288)/288
Step 3 — Back to Unix: round(…/300)×300
Outputs ts_adjusted_h3 (col M) and ts_adjusted_m15 (col AA) — join keys for Stack B
Python 3.11+ math.ceil pandas ≥2.0 numpy ≥1.26
⚙️
Stack B · Python
Mapping & Interpolation Engine
stack_b/engine.py — cols A→BB → BD–BM
H3 lookup — np.searchsorted (INDEX/MATCH type=1); maps each M15 row to parent H3 bar
M15 lookup — pandas merge on ts_adjusted_m15 (exact XLOOKUP)
AND-guard interp — linear interp for E–I; checks consecutive blocks & non-null guard
Regression — scipy linregress on 12-row window → clamped slope → AX/AY projection
2-pass model — Pass 1 every 15 min (INSERT); Pass 2 every 3 h (FILLBACK 11 rows)
Python 3.11+ pandas ≥2.0 numpy ≥1.26 scipy ≥1.12 APScheduler ≥3.10 httpx ≥0.27 pydantic ≥2.0
🔌
Stack C · Nest.js
REST + WebSocket API
bars.controller / bars.gateway
POST /bars/batch — UPSERT from Stack B; supports Pass 2 retroactive fills
GET /bars/latest — last N records; Redis-cached for <10 ms reads
WS bars:update — broadcasts each new M15 bar (Pass 1)
WS bars:fillback — broadcasts 11 retroactively filled bars (Pass 2)
Nest.js TypeScript TypeORM PostgreSQL Redis Socket.IO class-validator

Chart Visualisation
SsaChart · TrendBadge · MetricsBar
