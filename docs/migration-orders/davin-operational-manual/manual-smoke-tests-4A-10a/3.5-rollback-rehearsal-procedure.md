## 📝 Detailed Step-by-Step Instructions

### Step 1: Baseline Check (Flags = true)

Confirm that all 4 feature flags are set to `true` in your Next.js app environment from tests 3.1 through 3.4.

---

### Step 2: Revert Feature Flags to false

1. Go to Vercel Dashboard (or Railway Next.js service) for the Next.js web application.
2. Under Environment Variables, update all 4 flags to `false`:
   ```env
   MIGRATE_WRITE_APIS_MONEY_STRIPE=false
   MIGRATE_WRITE_APIS_MONEY_DLOCAL=false
   MIGRATE_WRITE_APIS_MONEY_ADMIN=false
   MIGRATE_WRITE_APIS_MONEY_DISBURSEMENT=false
   ```
3. Save and redeploy.

---

### Step 3: Re-Test All 5 Routes in PowerShell

Open **Windows PowerShell** and execute requests for each route (update URL host):

1. **Stripe Checkout:**

   ```powershell
   curl -X POST https://your-domain.com/api/checkout `
     -H "Authorization: Bearer <TEST_USER_JWT>" `
     -H "Content-Type: application/json" `
     -d '{"priceId": "price_1Pxxx_PRO_MONTHLY"}'
   ```

   _Pass Criteria:_ Returns **200 OK** handled by monolith Next.js route.

2. **Stripe Subscription Cancel:**

   ```powershell
   curl -X POST https://your-domain.com/api/subscription/cancel `
     -H "Authorization: Bearer <TEST_USER_JWT>"
   ```

   _Pass Criteria:_ Returns **200 OK** handled by monolith Next.js route.

3. **dLocal Payment Creation:**

   ```powershell
   curl -X POST https://your-domain.com/api/payments/dlocal/create `
     -H "Authorization: Bearer <TEST_USER_JWT>" `
     -H "Content-Type: application/json" `
     -d '{"country":"TH","paymentMethod":"P2P","planType":"MONTHLY","currency":"THB"}'
   ```

   _Pass Criteria:_ Returns **200 OK** handled by monolith Next.js route.

4. **Admin Code Distribution:**

