## 📝 Detailed Step-by-Step Instructions

### Step 1: Baseline Check (Flags = true)

Confirm that all 4 feature flags are set to `true` in Railway from tests 3.1 through 3.4.

---

### Step 2: Revert Feature Flags to false in Railway

1. Open `https://railway.app` → Select service **`trading-alerts-monolith`**.
2. Click the **`Variables`** tab.
3. Update all 4 flags to `false`:
   ```env
   MIGRATE_WRITE_APIS_MONEY_STRIPE=false
   MIGRATE_WRITE_APIS_MONEY_DLOCAL=false
   MIGRATE_WRITE_APIS_MONEY_ADMIN=false
   MIGRATE_WRITE_APIS_MONEY_DISBURSEMENT=false
   ```
4. Click **Save / Deploy**. Wait ~30 seconds for green deployment status.

---

### Step 3: Re-Test All 5 Routes in PowerShell

Open **Windows PowerShell** and execute requests for each route:

1. **Stripe Checkout:**

   ```powershell
   curl -X POST https://staging.trading-alerts.com/api/checkout `
     -H "Authorization: Bearer <TEST_USER_JWT>" `
     -H "Content-Type: application/json" `
     -d '{"priceId": "price_1Pxxx_PRO_MONTHLY"}'
   ```

   _Pass Criteria:_ Returns **200 OK** handled by monolith Next.js route.

2. **Stripe Subscription Cancel:**

   ```powershell
   curl -X POST https://staging.trading-alerts.com/api/subscription/cancel `
     -H "Authorization: Bearer <TEST_USER_JWT>"
   ```

   _Pass Criteria:_ Returns **200 OK** handled by monolith Next.js route.

3. **dLocal Payment Creation:**

   ```powershell
   curl -X POST https://staging.trading-alerts.com/api/payments/dlocal/create `
     -H "Authorization: Bearer <TEST_USER_JWT>" `
     -H "Content-Type: application/json" `
     -d '{"country":"TH","paymentMethod":"P2P","planType":"MONTHLY","currency":"THB"}'
   ```

   _Pass Criteria:_ Returns **200 OK** handled by monolith Next.js route.

4. **Admin Code Distribution:**

   ```powershell
   curl -X POST https://staging.trading-alerts.com/api/admin/affiliates/<ID>/distribute-codes `
     -H "Authorization: Bearer <ADMIN_USER_JWT>" `
     -H "Content-Type: application/json" `
     -d '{"count":1,"reason":"Rollback test"}'
   ```

   _Pass Criteria:_ Returns **200 OK** handled by monolith Next.js route.

5. **Disbursement Batch Execution:**
   ```powershell
   curl -X POST https://staging.trading-alerts.com/api/disbursement/batches/<ID>/execute `
     -H "Authorization: Bearer <ADMIN_USER_JWT>"
   ```
   _Pass Criteria:_ Returns **200 OK** or 400 status check handled by monolith Next.js route.
