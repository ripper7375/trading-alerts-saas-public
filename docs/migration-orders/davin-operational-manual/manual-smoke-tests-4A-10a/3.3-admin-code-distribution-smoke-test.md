## 📝 Detailed Step-by-Step Instructions

### Step 1: Enable Feature Flag in Next.js App (DONE)

1. Go to Vercel Dashboard (or Railway Next.js service) for the Next.js web application.
2. Under Environment Variables, set:
   ```env
   MIGRATE_WRITE_APIS_MONEY_ADMIN=true
   ```
3. Save and redeploy.
   (DONE)

---

### Step 2: Execute Admin Code Distribution Request in PowerShell

1. Open **Windows PowerShell**.
2. Copy the command below (update URL host, `<ADMIN_USER_JWT>`, and `<AFFILIATE_ID>`):

```powershell
curl -X POST https://your-domain.com/api/admin/affiliates/<AFFILIATE_ID>/distribute-codes `
  -H "Authorization: Bearer <ADMIN_USER_JWT>" `
  -H "Content-Type: application/json" `
  -H "Idempotency-Key: test-admin-codes-001" `
  -d '{
    "count": 5,
    "reason": "Staging 4A-10b Smoke Test"
  }'
```

3. Right-click inside PowerShell to paste → Press **Enter**.

---

### Step 3: Verify Success Response (200 OK)

Check the JSON output displayed in PowerShell:

```json
{
  "success": true,
  "distributedCount": 5,
  "message": "Successfully distributed 5 codes to affiliate"
}
```

_Pass Criteria:_ Returns `success: true` and `distributedCount: 5`.

---

### Step 4: Test Non-Admin User Authorization Rejection (403 Forbidden)

Execute the distribution command using a non-admin user JWT token (`<NON_ADMIN_JWT>`):

```powershell
curl -X POST https://your-domain.com/api/admin/affiliates/<AFFILIATE_ID>/distribute-codes `
  -H "Authorization: Bearer <NON_ADMIN_JWT>" `
  -H "Content-Type: application/json" `
  -d '{ "count": 5, "reason": "Unauthorized test" }'
```

_Pass Criteria:_ Returns HTTP status **`403 Forbidden`** (enforced by `AdminGuard` in `money-service`).

---

### Step 5: Test Count Bounds Check (count > 50)

Execute the distribution command with `count: 100` (exceeding maximum 50):

```powershell
curl -X POST https://your-domain.com/api/admin/affiliates/<AFFILIATE_ID>/distribute-codes `
  -H "Authorization: Bearer <ADMIN_USER_JWT>" `
  -H "Content-Type: application/json" `
  -d '{ "count": 100, "reason": "Invalid count test" }'
```

_Pass Criteria:_ Returns HTTP status **`400 Bad Request`**.

---

### Step 6: Check Database Tables in Railway

1. Go to **Railway Dashboard** → Click database service **`Postgres`** → Click **`Data`** tab.
2. Select table **`AffiliateBonusCode`**:
   - Verify **5 new bonus code rows** exist linked to `<AFFILIATE_ID>`.
3. Select table **`OutboxEvent`**:
   - Verify **1 new row** exists with `aggregate_type = 'AFFILIATE'` and `event_type = 'CODES_DISTRIBUTED'`.
