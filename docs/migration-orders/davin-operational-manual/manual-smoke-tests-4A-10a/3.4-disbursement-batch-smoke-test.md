## 📝 Detailed Step-by-Step Instructions

### Step 1: Enable Feature Flag in Railway

1. Open `https://railway.app` in your browser.
2. Select your project → Click on service **`trading-alerts-monolith`**.
3. Click the **`Variables`** tab.
4. Add or update the variables:
   ```env
   MIGRATE_WRITE_APIS_MONEY_DISBURSEMENT=true
   DISBURSEMENT_PROVIDER=MOCK
   ```
5. Click **Save / Deploy**. Wait ~30 seconds for green status.

---

### Step 2: Execute Batch Execution Request in PowerShell

1. Open **Windows PowerShell** (Windows Key → type `PowerShell` → Enter).
2. Copy the command below (replace `<ADMIN_USER_JWT>` and `<BATCH_ID>` with an existing test batch in state `PENDING`):

```powershell
curl -X POST https://staging.trading-alerts.com/api/disbursement/batches/<BATCH_ID>/execute `
  -H "Authorization: Bearer <ADMIN_USER_JWT>" `
  -H "Content-Type: application/json" `
  -H "Idempotency-Key: test-batch-execute-001"
```

3. Right-click inside PowerShell to paste → Press **Enter**.

---

### Step 3: Verify Success Response (200 OK)

Check the JSON output displayed in PowerShell:

```json
{
  "success": true,
  "batchId": "<BATCH_ID>",
  "status": "COMPLETED",
  "processedCount": 1
}
```

_Pass Criteria:_ Returns `success: true` and batch status `"COMPLETED"`.

---

### Step 4: Test Double Execution Protection (Re-Execution Attempt)

Re-run the exact same `curl` execution command against `<BATCH_ID>` in PowerShell.

_Pass Criteria:_ Returns **cached 200 OK response** (via `IdempotencyInterceptor`) or **400 Bad Request** error (`Cannot execute batch in state COMPLETED`), preventing double payout transaction generation.

---

### Step 5: Check Database Tables in Railway

1. Go to **Railway Dashboard** → Click database service **`Postgres`** → Click **`Data`** tab.
2. Select table **`PaymentBatch`**:
   - Verify `status` = `'COMPLETED'`.
3. Select table **`DisbursementTransaction`**:
   - Verify transactions are created, each linked to a `@unique` `commission_id`.

---

### Step 6: Verify Money-Service Logs in Railway

1. Go to **Railway Dashboard** → Click service **`money-service`**.
2. Click the **`Logs`** tab.
3. Observe log evidence:
   ```text
   [INFO] forwardWriteRequestToMoneyService: Forwarding POST /api/disbursement/batches/<BATCH_ID>/execute -> money-service /v1/disbursement/batches/<BATCH_ID>/execute
   [INFO] DisbursementBatchesController: Executing batch <BATCH_ID> (Provider: MOCK)
   [INFO] PaymentOrchestrator: Batch <BATCH_ID> execution finished cleanly
   ```
