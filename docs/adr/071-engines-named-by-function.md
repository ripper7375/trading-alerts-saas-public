# ADR-071: Engines named by function

- **Status:** Settled
- **Date:** 2026-09-30
- **Section:** 7 · Platform & governance (deck decision 7.2: Engine names)
- **Architecture:** [STACK-D-ARCHITECTURE.md](../STACK-D-ARCHITECTURE.md) §7.2

## Decision

Names by function; old numbers kept as aliases.

## Alternative not chosen

Keep numbers.

## Why

After the retirements, engine numbers (1.5A, 1.5E …) are hard to follow.
