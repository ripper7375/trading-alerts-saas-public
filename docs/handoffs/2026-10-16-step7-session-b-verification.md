## 1. Task 1: Finding F1, Windows CRLF in `scripts/reply/eval-run.js`

**The defect.** Lines 67 to 75 read the script's own header comment for `--help`:

```js
const HELP = fs.readFileSync(__filename, 'utf8').split('\n').slice(1).join('\n').match(/\/\*\*\n([\s\S]*?)\n \*\//)[1] ...
```

`HELP` is a module-level constant, so the `.match(...)[1]` runs when the module loads. With CRLF line endings `/**` is followed by `\r\n`, the match is `null`, and the load throws `TypeError: Cannot read properties of null (reading '1')`. Any invocation fails, not just `--help`.

**The fix** (one line plus a comment): `.replace(/\r\n/g, '\n')` before `.split('\n')`. The CRLF is removed from the text before it is cut into lines, so the extracted manual has no `\r` in it.
