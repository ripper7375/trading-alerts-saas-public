## 7. Problems and surprises the next session must know

1. **The literal thresholds flag every active channel.** All six readings (v1, v3, v4 × M5, M15) end `MCD0_M5_M15_DEFECT`; only R² and the fit ratio fail, coverage, geo ratio and skew never do. This is what walkthrough Part 0 item 3 expected, so the shadow period must measure it. The schema says low or negative Model B R² is structurally expected for lines fitted to centroids or touches; the thresholds are settled (ADR-019) and the concept does not reopen them. Boundary-close values: v4 M5 `cherry_a` R² A 0.6876 against 0.70, v4 M15 `non_b` fit ratio B 1.51 against 1.50, v1 M15 `non_b` R² B 0.655 against 0.65.
2. **Only one real-data state besides the all-defect one.** v3 with the M15 setting changed to `non_a` (a real, fully qualified channel) gives `MCD0_M5_DEFECT`. `MCD0_ALL_QUALIFIED` and `MCD0_M15_DEFECT` need synthetic bundles, because no real M5 channel qualifies (the fractal EDT fails the geo ratio on all three slots).
3. **`window_span_bars` includes the still-open bar,** as the schema comment says ("to the live bar, inclusive"), the same fact ADR-083 handles with `t_edt_open_bar_rows`. The 60-bar floor never binds on the fixtures (the smallest span is 314), so the answer to (a) changes no reading.
4. **MCD0 is a new reader of the fit fields** (R², MSE, skew, offsets). The open question of whether the statistics' fit used the forming bar ([waiting-on](../../.claude/state/waiting-on.md)) therefore reaches MCD0 as well; the item now lists it. Not a blocker for the build.

The plan has to say how the shared checks apply to a bar-less gate; the standard allows a spec to adapt each tier's content (§6).
